# BQ (working title)

A mobile game for Android and iOS. You journey across a 3D map of the United Kingdom, from Roman times to today, and it helps you prepare for the *Life in the UK* test.

**Status:** specification stage.
- [docs/SPEC.md](docs/SPEC.md): the game specification.
- [docs/LEARNING_DESIGN.md](docs/LEARNING_DESIGN.md): how the game teaches the handbook.

Milestone 1, the journey skeleton (a test build for Android), starts after the spec is approved.
